# Richman v0.3 玩家体验审计（第一轮）

- 审计日期：2026-09-27
- 起点版本：`fe3bfd1`（v0.2.0），136 个规则测试全部通过
- 审计方式：**真实渲染每一屏并逐张看图**，不是读代码猜问题。
  所有截图由 `tools/ui_shots.py` 生成（可复现），存于 `docs/reports/shots_v03/`。
- 审计原则：只记录「玩家真的会遇到、且会造成困惑/卡住/难看」的问题。
  已能正常工作且不需要改的东西不写进来充数。

审计覆盖的路径：
主菜单 → 单人配置 → 局域网建房 / 加入 → 大厅 → 开局 → 掷骰 → 移动 →
买地 → 升级 → 交租 → 道具 → 商店 → 事件 → 债务 → 破产 → 结算 → 再来一局。

---

## 0. 结论摘要

v0.2 的**规则与网络**是健康的（这一点上一轮已经验证过），
但**表现层仍然停留在「工程演示」阶段**，而且存在 **1 个真正阻断联机的 P0**：

> 局域网界面里的 5 个输入框根本没有注册进 `widgets`，
> 因此它们**看不见、点不到、打不了字**。
> 玩家没有别的办法输入房主的 IP —— 也就是说，
> 「把 dist 文件夹发给室友，他双击 exe 输入我的 IP」这条主流程，
> 在图形界面上是走不通的。

这类问题的性质是：**代码在跑，功能不在**。所以这一轮的审计重点不是
「有没有实现」，而是「玩家能不能用」。

| # | 问题 | 证据 | 玩家感受 |

| P0-1 | **局域网界面输入框不可见且不可交互**。`LanSetupScene` 创建了 `name_input / host_input / port_input / room_input / port_host_input`，但 `self.widgets` 只有两个 Button，`Scene.handle_event` 只遍历 `widgets` → 点击不聚焦、按键不输入、也不绘制 | 截图 `v03_04b_lan_join.png` 只有「昵称 / 房主 IP / 端口」三个标签，字段位置一片空白；实测点击 IP 框后 `focused=False` | 「加入房间」页面像坏了。无法输入 IP，只能连上次连过的地址 |
| P0-2 | 单机配置页的「地图 / 规则」选择器与角色选择条**互相重叠**：选择器 `(620,380,860,76)` 压在 12 张角色卡 `(120,350,900,116)` 上 | 截图 `v03_03_local_setup.png`：「地图」框盖住了第 8～12 个角色卡片 | 有 5 个角色选不到，点下去会变成切地图 |

## P1 —— 明显影响理解与观感

| # | 问题 | 证据 | 玩家感受 |
| --- | --- | --- | --- |
| P1-1 | **福运格 / 灾祸格 / 商店格退化成蓝色地产**。`theme.TILE_TYPE_COLORS` 里没有 `FORTUNE / DISASTER / SHOP` 三项，`.get(..., "t_property")` 一律回退到地产蓝；`_draw_static_tile` 的图标表同样缺这三种 | 截图：`好运街角`（福运）、`便利店`（商店）与 `大学城`（地产）颜色完全一样 | 掉进福运和掉进地产前的视觉预期一样，看不出会变好还是变坏 |

| P1-4 | **地图中央大面积浪费**：只有一行「该你行动了」、一个奖金池、一行几乎看不见的 `RICHMAN` 字样，和一层 alpha 14～30 的城市剪影 | 截图 `v03_06_game_start.png` | 中间一大块空白，看起来像没做完；骰子/最近事件/回合信息全挤在右侧小栏 |
| P1-5 | **弹窗按钮与面板错位**。`Modal._panel()` 返回的是按 `ease_out_back` 缩放后的矩形，但按钮坐标仍按未缩放的 `self.rect` 计算 → 弹出动画期间按钮溢出面板 | 截图 `06c_modal_2.png`：「购买 3,000」按钮横跨到右侧栏，「放弃」掉到面板下方 | 每次弹窗都有一次可见的“抖一下”，廉价感很强 |

## P2 —— 体验损失，值得改

| # | 问题 | 证据 | 玩家感受 |
| --- | --- | --- | --- |
| P2-1 | **金钱变化只有 4 种事件有浮字**（经过起点 / 租金 / 买地 / 升级）。抵押、赎回、卖地、商店购买、事件罚款、奖金池、保释金都只是「数字变小了」 | `game_scene._present_event` 白名单 | 「我的钱怎么少了 3000？」 |
| P2-2 | **事件卡是 420×300 的临时浮层**，1 秒内自己消失，不带极性（福运/灾祸）区分，也不告诉你具体加了多少钱 | `CardFlipAnimation` | 事件一闪而过，看不懂发生了什么 |
| P2-3 | **AI 使用道具没有演出**，只在日志里出现一行「电脑丙 使用了道具『停留卡』」 | 截图日志区 | 对面的操作完全不可见，感觉被偷袭 |
| P2-4 | **掷骰 → 停下 → 移动 之间没有节奏**：`_sync_animations` 按阶段即时触发动画，阶段时长恰好等于动画时长，肉眼上骰子还没停稳棋子就走了 | 代码 `_sync_animations` | 核心循环不够爽 |
| P2-5 | **资产面板没有结构**：只是 3 列卡片网格 + 顶部 4 个数字；债务模式下欠款/现金/还需筹集只塞在标题里一行，且不会实时刷新进度 | 代码 `asset_panel.py` | 债务处理时看不到「还差多少」 |
| P2-6 | **设置页布局错乱**：左侧「音频」分组框只有 `180..370`，但静音开关在 `y=500`、调试开关在 `y=720`，都跑到框外；没有游戏节奏（慢/标准/快）、没有音效/音乐开关、没有详细日志开关 | 代码 `settings_scene.py` | 设置页看起来是半成品 |
| P2-7 | **大厅没有「复制 IP」**，IP 埋在「房间信息」列表第 3 行；没有联系人提示（「把这行发给室友」） | 截图 `v03_09_lobby_host.png` | 房主要手抄 IP，还容易抄错 |
| P2-8 | **断线没有重连**：`GameClient.reconnect()` 写好了但**从未被调用**。掉线只会弹「与房主的连接已断开」然后踢回主菜单，本局直接作废 | 代码 `app.py update()` | 掉线 = 毁局，这是 v0.2 明确没验证到位的能力 |
| P2-9 | **没有局域网诊断入口**，没有新手教程入口，主菜单 7 个按钮里没有这两项 | 截图 `v03_01_menu.png` | 连不上时玩家只能自己猜 |
| P2-10 | 事件日志是纯文本流水，普通事件与关键交易的视觉层级弱（只有 11 种事件类型分色） | 截图日志区 | 想回看「刚才谁给我转了钱」很难定位 |

## 改进顺序（本轮实际执行顺序）

1. **P0 全部** + P1-5/6/7/8（基础可用性与排版）—— 先让界面「不出错」
2. **UI Design System**（`theme` + `icons` + `widgets` 收口），为后面所有界面提供统一语言
3. **P1-1/2/3/4**（地图视觉重做，本阶段最高视觉优先级）
4. **P2-1/2/3/4**（骰子 / 移动 / 金钱 / 事件的演出）
5. **P1-9 + 目标选择**（道具 UX）
6. **P2-5**（资产与债务三栏）
7. **P1-12**（结算重设计）
8. **P0-1/2/3 + P2-7/8/9**（LAN 产品化、重连、诊断）
9. **P2-6**（设置与节奏）
10. 教程 / 音效 / 打包 / 平衡 / 稳定性 / 文档

## 明确不动的东西

- `GameState` 字段、`seed + counter` 随机、`canonical_hash`
- `Command` / `PendingDecision` / `Controller` 三层抽象
- `GameEngine` 的阶段机与规则计算
- TCP + 长度前缀 + JSON 传输
- `BoardView` 的静态层缓存策略（本轮只改画什么，不改怎么缓存）
- `SceneManager` 场景栈
- 已有的 136 个测试
