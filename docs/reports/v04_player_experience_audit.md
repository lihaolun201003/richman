# Richman v0.4 · 玩家视角体验审计

- 审计时间：2026-09-27
- 审计基准：`740585d`（v0.3.0）
- 审计方式：真实窗口/离屏渲染逐屏截图（`docs/reports/shots_v03/`）+ 逐屏人工阅读 +
  「一个没见过这个项目的人能不能自己走通」的判定
- 审计人视角：**普通玩家**（不懂 Python、不看源码、只有一台电脑）

判定标准只有一句：**第一次玩的人，是否知道下一步该干嘛。**

## P1 · 让玩家困惑、必须猜、或产生错误预期

| # | 位置 | 问题 | 证据 |
| --- | --- | --- | --- |
| P1-1 | 对局开局瞬间 | 中央卡片写「该你行动了」，紧接着下面一行写「等待其他玩家…」——**同一屏自相矛盾**（开局 GAME_SETUP 阶段 `interaction_state()` 落到 WAITING）。 | `shots_v03/v03_game_start.png` |
| P1-2 | 局域网建房页 | 副标题说「把 IP 和端口告诉朋友」，但**建房页上没有任何 IP**；玩家必须先建房、进大厅、再去大厅找 IP。信息在最需要的地方缺席。 | `shots_v03/v03_lan_host.png` |
| P1-3 | 局域网建房/加入页 | 「选择角色（…）」标签与第一行角色卡**重叠压字**（两个页面都有）。 | `shots_v03/v03_lan_host.png` / `shots_v03/v03_lan_join.png` |
| P1-4 | 加入房间页 | 搜不到房间时只有一句「正在搜索…」，**没有告诉玩家「大概多久能搜到」「搜不到该怎么办」**；右侧大面板 90% 是空白。 | `shots_v03/v03_lan_join.png` |
| P1-5 | 加入房间页 | 输入框只接受纯 IP。室友发来「192.168.1.10:28080」（**这是最常见的复制粘贴形式**）会直接连接失败。 | `src/ui/setup_scenes.py:531-556` |
| P1-6 | 大厅 | 玩家卡只显示「已准备 / 未准备 / 电脑」。**看不出谁掉线了、谁被 AI 接管、谁正在重连**；房主也看不出「掉线多少秒了」。 | `shots_v03/v03_09_lobby_host.png`；`src/ui/lobby.py:395-408` |
| P1-7 | 大厅 | 开始按钮只写「等待准备…」，**不写具体在等谁**。房间信息里也没有游戏版本，无法判断队友版本是否一致。 | `shots_v03/v03_09_lobby_host.png` |
| P1-8 | 主菜单 | 「局域网诊断」与「创建/加入房间」平级，占了主菜单第 8 个位置；主菜单**没有「局域网联机」聚合入口**，第一次来的人要在 8 个按钮里自己找联机。 | `shots_v03/v03_menu.png` |
| P1-9 | 预设 | 只有 3 个预设（快速/标准/休闲），**缺少面向 5～6 人的短局预设**；人数选到 5、6 时没有任何提示（实际 6 人标准局约 60 分钟）。 | `config/default.json` |
| P1-10 | 设置 | **没有「AI 演出速度」**，也没有「重新打开新手教程」的入口（教程只会在第一次出现，关掉后找不回来）。 | `shots_v03/v03_settings.png` |

## P2 · 体验粗糙、信息层级差

| # | 位置 | 问题 |
| --- | --- | --- |
| P2-1 | 诊断页 | 6 行「本机状态」里混着「协议版本 2」这种开发字段；左面板 540 高只用了 8 行，大片空白。 |
| P2-2 | 诊断页 | 提示是**固定的 5 条清单**，不是按当前状态给的动态结论：本机是 `127.0.0.1`、`169.254.x.x`、有多个网卡、UDP 搜不到——四种情况给的提示完全一样。 |
| P2-3 | 诊断页 | 没有「测试连接」功能：玩家想验证「室友的 IP 到底通不通」只能回加入页盲试，且所有失败都只显示「连接失败」。 |
| P2-4 | 对局 | 事件日志面板标题是「事件日志」，混着 `TURN_START` 之类的阶段行；没有「本局记录」的玩家视角（谁买了什么、谁付了谁多少）。 |
| P2-5 | 对局 | 破产只有一句横幅「XXX 破产退出」，**没有债务/资产/地产数量**，玩家不知道他是怎么死的、地归谁了。 |
| P2-6 | 结算 | 有排名、趣味称号、统计表，但**没有「本局时间线」**：谁在哪一轮完成的垄断、谁先破产，全都没有。 |
| P2-7 | 对局 | AI 回合里玩家看到的是「等待 XXX 操作…」，**看不到 AI 在干什么**；AI 决策本身几十毫秒，却固定等 `think_sec=0.45s`，体感是「发呆」。 |
| P2-8 | 演出 | 所有演出共用一个队列，破产/掉线这类关键事件**可能被普通收租横幅挤掉**（`banners` 只保留最后 4 条）。 |
| P2-9 | 教程 | 教程是「主菜单点进去的独立模式」，**第一次进游戏的玩家不会被引导**；没有「以后不再显示」。 |
| P2-10 | 打包/排障 | 出问题后普通玩家**不知道要给开发者什么信息**，只能截图或口述。 |

- **P0-1 ~ P0-5**：全部修复（含预设字段补全、诊断端口真实化、两处布局越界）。

  大厅状态机、阻塞原因、联机聚合入口、聚会模式预设、AI 演出速度与教程开关）。

  AI 回合提示、演出优先级、首启引导、诊断包导出）。
- **P3**：全部处理。
