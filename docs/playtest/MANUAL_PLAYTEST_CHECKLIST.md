# Richman 真人试玩清单（v0.3）

这份清单是给**真人和室友一起玩**的时候用的，不是自动化测试的替代品。
自动化能证明「代码不崩、状态一致、钱算得对」，
但手感、节奏、两个人之间是不是能顺利连上，只有真人能回答。

用法：两个人两台电脑，按顺序走一遍。每条打完勾或记一句问题，
末尾「主观感受」那几栏一定要填——那是自动化测不出来的部分。

准备：
- 两份 `dist\Richman\` 文件夹（**整个文件夹**，不是只复制 exe）
- 两台电脑连同一个 WiFi / 局域网
- 房主的防火墙弹窗点了「允许（专用网络）」

---

## A. 联机能不能连上（最重要）

- [ ] A1 两台电脑各自双击 `Richman.exe`，都能进主菜单（没有报错弹窗、没有缺字方块）
- [ ] A2 房主：创建局域网房间 → 能进大厅，大厅里**大字显示本机 IP**（形如 192.168.x.x）
- [ ] A3 房主：点「复制连接信息」，粘贴到记事本，得到 `IP:端口`（粘贴出来的内容正确）
- [ ] A4 客户端：主菜单 →「加入房间」→ 能**看见并点到输入框**、能打字（v0.2 这里点不动）
- [ ] A5 客户端：手动输入房主的 IP 与端口 → 连接 → 进入房主的大厅
- [ ] A6 客户端：点右侧「搜索局域网房间」→ 列表里出现房主的房间 → **直接点房间就能加入**
- [ ] A7 客户端：故意输错 IP（例如 `1.2.3.4`）→ 出现中文错误提示（不是英文报错、不是卡住）
- [ ] A8 客户端：昵称改成和房主一样 → 应该被拒绝并说明「昵称已被使用」
- [ ] A9 房主：房间信息里能一眼看到「人数 / 端口 / 地图 / 规则」

## B. 开局

- [ ] B1 客户端：能选角色，悬停能看到该角色的被动能力与 AI 性格
- [ ] B2 客户端：按 `R` 准备 → 房主那边看到「已准备」
- [ ] B3 房主：加 1～2 个电脑玩家补位
- [ ] B4 房主：切换地图与规则 → 客户端大厅里同步显示新地图与新规则
- [ ] B5 房主：点「开始游戏」→ 两台电脑几乎同时进入对局
- [ ] B6 两边的**玩家卡片顺序、颜色、资金**完全一致

## C. 一局真的能打完

- [ ] C1 轮到自己时，能点「掷骰子」（也试试空格键）
- [ ] C2 骰子会滚动 0.5～1 秒再停下，然后棋子**逐格**走过去（不是瞬移）
- [ ] C3 落到无主地产 → 弹窗能看懂售价 / 当前租金 / 满级租金 → 买下
- [ ] C4 买下后棋盘上那块地**能看到自己的颜色与编号**，升到 1 级能看到小楼
- [ ] C5 对手踩到你的地 → 他看到「要付多少」，你看到「收到多少」（浮动数字）
- [ ] C6 按 `I` 打开资产面板：左边列表 / 中间详情 / 右边操作，能升级、能抵押、能赎回、能出售
- [ ] C7 升级后棋盘上的建筑外观变化（1 层 → 2 层 → 3 层）
- [ ] C8 踩到福运格 → 弹出绿色「福运」事件卡，写着标题、描述、实际效果
- [ ] C9 踩到灾祸格 → 弹出红色「灾祸」事件卡
- [ ] C10 踩到商店格 → 能买一张道具（看清楚价格与时机）
- [ ] C11 右侧手牌：**灰掉并带锁**的卡，鼠标悬停会说明为什么现在不能用
- [ ] C12 点一张可用的卡（例如指定骰子卡）→ 能选目标（弹窗或直接在棋盘上点）→ 生效
- [ ] C13 对手使用道具时，屏幕上有横幅提示「谁 用了什么 目标是谁」
- [ ] C14 现金不够付租 → 进入债务处理：顶部显示「欠款 / 现存现金 / 仍需筹集」，且数字随操作实时变化
- [ ] C15 债务处理里只能抵押或出售，其它按钮禁用并写明原因
- [ ] C16 有人破产 → 提示「破产退出，资产移交债权人」，游戏继续
- [ ] C17 打到只剩一人（或轮数上限）→ 弹出结算界面
- [ ] C18 结算界面：冠军、排名表、玩家统计、趣味称号都能看清，值得截图
- [ ] C19 房主点「再来一局」→ 双方回到大厅并能立刻开下一局
- [ ] C20 客户端在结算界面看到的按钮是「返回大厅」，并提示「由房主决定是否再来一局」

## D. 掉线与重连（v0.3 重点）

- [ ] D1 对局中把客户端的网线拔掉 / 关掉 WiFi
- [ ] D2 客户端：屏幕出现「与房主的连接已中断 / 正在尝试重新连接…」以及倒计时
- [ ] D3 房主：能继续操作，日志显示「XX 与房间失去连接」，本局不中断
- [ ] D4 **30 秒内**把网络接回去 → 客户端应该自动重连成功（提示「已重新连接」）并能继续操作
- [ ] D5 故意等超过 30 秒 → 房主日志显示「由 AI 代为操作」，此时接回网络仍能重连接回操作
- [ ] D6 直接关掉房主的游戏（结束房间）→ 客户端收到提示 → 回主菜单，不卡死

## E. 界面与设置

- [ ] E1 主菜单每个按钮都点一遍：图标正常（**没有方框豆腐块**）、文字不重叠
- [ ] E2 设置里把游戏节奏切成「快」→ 再开一局，动画明显更快（规则与结果不变）
- [ ] E3 设置里把字体调到「大」→ 各页面文字不重叠、不溢出
- [ ] E4 全屏 / 窗口切换（`F11`）正常，`Alt+Tab` 回来画面正常
- [ ] E5 主菜单 →「局域网诊断」：本机 IP / 端口 / 发现服务状态都显示，且是真的（跟 `ipconfig` 对得上）
- [ ] E6 主菜单 →「新手教程」：跟着右下角提示能走完 8 步；教程用的是真实规则（能真的买地、升级、用道具）

## 已知需要真机确认的点（开发者视角）

1. **跨机联机从未在真实两台电脑上验证过**（开发只有一台机器）。
   防火墙提示、AP 隔离、多网卡选错 IP 都只能靠这份清单来踩。
2. **UDP 自动发现同样是本机回环验证**。
   如果搜不到房间，直接看第 A5 条（手动输入）能不能用——手动永远是保底方案。
3. **重连逻辑已经用真实 TCP 自动化验证过**（`tools/reconnect_demo.py` 18/18 通过，
   包含「拔网线 → 重连 → 继续操作」与「超时 AI 接管 → 接回控制权」），
   但**没有真的拔过网线**，物理断网与模拟断开的差别只有真机能覆盖。
4. 手感类问题（动画快慢、弹窗节奏）无法自动化判断，请照实填 F 段。
